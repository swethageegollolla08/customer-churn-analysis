# Customer Churn Analysis Dashboard

## Project Overview

Analyzed 10,000 bank customer records using SQL, Excel, and Power BI to identify customer churn patterns and at-risk customer segments.

## Tools Used

- SQL
- Excel
- Power BI

## Key Findings

- 2,038 customers churned (20.38%)
- 99.5% observed churn among customers who reported complaints
- 82.7% churn among customers with 3 products
- 100% churn among customers with 4 products

## Dashboard

Interactive Power BI dashboard analyzing churn by geography, age, tenure, product holdings, activity, and complaint status.
